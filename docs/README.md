# Clube de Desbravadores Estrela de Aço

Site institucional do Clube de Desbravadores Estrela de Aço — Ipatinga/MG,
desde 2002.

## Sobre o projeto

O site apresenta o clube para crianças, adolescentes, pais e a comunidade,
conduzindo o visitante por uma jornada: descobrir o clube, entender o que
ele faz, conhecer as atividades, consultar a agenda e participar.

## Tecnologias

HTML5, CSS3 e JavaScript puro — sem frameworks ou bibliotecas pesadas.

## Estrutura

Veja `docs/architecture.md` para a explicação completa da organização de
pastas, convenção de nomes e como adicionar uma página nova.

Veja `docs/design-system.md` para a paleta de cores, tipografia e todas as
decisões de conteúdo/design já tomadas.

## Como rodar localmente

Não há build nem instalação. Basta abrir `index.html` no navegador.

> Algumas páginas futuras podem depender de dados carregados via
> JavaScript (ex.: agenda). Nesse caso, rodar com a extensão **Live
> Server** do VS Code evita bloqueios de CORS que ocorrem ao abrir o
> arquivo direto (`file://`).
